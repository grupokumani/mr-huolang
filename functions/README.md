# functions/

Reservado para a FASE 4 (Backend). O Cloudflare Pages detecta automaticamente
ficheiros `.js` dentro de `functions/` e transforma-os em Cloudflare
Functions/Workers — sem configuração adicional, sem custo extra no plano
gratuito.

Exemplo futuro: `functions/api/produtos.js` ficará disponível em
`https://<o-teu-site>.pages.dev/api/produtos`.

Não apagar esta pasta, mesmo estando vazia agora.
